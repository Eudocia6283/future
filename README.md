# 预言书 · Liber Prophetiae

一本由线条画成、会对话的魔法书，为人工智能专业的本科生做职业生涯规划。

规划分五步：个人画像、职业筛选、发展方向、学习资源、实践机会。目前第一步「个人画像」已完整实现，其余四步暂由一次推演给出（命途、学习之章、实践之章与临别箴言），以画像为依据。

**个人画像。** 翻开书封后，预言书一问一答地描绘你：画像分为基本处境、学业基础、实践经历、兴趣倾向、工作风格、价值目标、资源约束七个维度，共 26 个条目（年级、升学意向、数学基础、每段项目与竞赛、感兴趣的领域、看重什么、每周可投入时间、英语……）。每回答一次，模型便把回答拆进各个条目，附上原话作依据并标注把握程度，再挑一个尚不清楚的条目发问；问题分单选、多选、1–5 刻度和自由叙述四种，都可以另写补充。每个条目最多问两次；所有必需条目都有了依据、且至少回答了 8 次后，预言书收尾，一般在 13–20 问之间，至多 24 问。页脚的七枚菱形随了解程度逐渐填满。

问完后，书页上是「你的画像」：左页是关键词云（字号表示这一点在你身上有多突出，颜色表示所属维度），右页是称号与四段文字画像。下一跨页列出预言书还拿不准的地方，可以点选其一写下实情，或指出任何画得不像之处，预言书会据此重绘；认可后再推演命途。之后的各步直接使用这段文字画像。

书页可以随时往回翻（页脚的「前页 / 后页」或方向键），重读之前的问答与预言。中途点「合上书」会在书里夹上一枚书签：封面上露出写着位置（如「第三问」「画像」）的纸签，下次翻开时回到那一页继续；若合上时预言书正在思考，翻开后会接着把这一步推演完。点「取下书签」则放弃这次进度，下次重新开始。进度保存在浏览器的 localStorage 中，刷新页面也不会丢失。

封面是深色布面，带斜纹布纹、金色内框与角花，并露出书页边与底板的厚度。画面由多层交叠而成：底层是被封面边缘裁切的淡色五角星法阵，一道流光沿星线游走；其上是空心大字「预言」，「言」在眼睛之后、「预」压在眼睛之前，与眼睛互相遮挡；眼睛仿照 Atelier Portal 门绘制：两层杏仁形眼睑交织穿插，在眼角交叉成 X，虹膜是三层圆叠成的符文，外围有金色轮廓、虚线回响与涟漪，会不时眨眼，瞳孔跟随鼠标，鼠标靠近时眼睑松开、金线描出，翻开书时合上。顶部与底部是小字题签，拉丁文书名竖排在翻口一侧。翻开后，深色书板框住纸色书页。

设计语言沿用 Eudocia's Magical Atelier：白底、紫藤与桃金色的细线（书本本身为深色布面）、左上角的 E. 标志、三层旋转并随鼠标视差的魔法阵（预言书思考时加速发光）、萤火虫粒子、点击涟漪和悬停微光。

## 技术栈

- React 19 · TypeScript · Vite · Tailwind CSS 4 · Motion
- 内联 SVG 绘制书本、翻页、法阵与雷达图
- Gemini API（`@google/genai`，结构化 JSON 输出），由 Vite 开发/预览服务器中的中间件代理，API Key 不会进入浏览器

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
cp .env.example .env   # 填入 GEMINI_API_KEY
npm run dev
```

打开 http://localhost:3000 。

不填 `GEMINI_API_KEY` 时，预言书以**演示模式**运行：使用内置的一套问答与预言，适合离线演示；页面右下角会显示 MOCK 标记。

| 变量 | 说明 |
| --- | --- |
| `GEMINI_API_KEY` | Gemini API Key，留空则进入演示模式 |
| `GEMINI_MODEL` | 模型 ID，默认 `gemini-flash-latest` |
| `GEMINI_BASE_URL` | 可选，中转地址 |
| `HTTPS_PROXY` | 可选，访问 Gemini 所用的 HTTP 代理，如 `http://127.0.0.1:7890` |

修改 `.env` 后需要重启 `npm run dev`。

## 项目结构

```text
├── shared/oracle.ts          # 前后端共用的类型与词表：五个步骤、画像的维度与条目、推荐方向
├── server/
│   ├── oracle.ts             # /api/oracle 处理器：调用 Gemini 或演示脚本
│   ├── prompts.ts            # 提问、画像与预言的系统提示词
│   ├── schema.ts             # Gemini 输出的 JSON Schema 与校验整理（画像条目的合并与把握程度）
│   └── mock.ts               # 演示模式的问答脚本、逐步填写的画像与预言
├── src/
│   ├── App.tsx               # 场景：背景法阵、萤火虫、涟漪、页眉
│   ├── oracle/useOracle.ts   # 对话状态机：提问 → 思考 → 推演 → 预言，并存入 localStorage
│   ├── book/
│   │   ├── Book.tsx          # 书的编排：封面、翻开、跨页内容、翻页
│   │   ├── geometry.ts       # 跨页 / 单页两种版式的几何与翻页矩阵
│   │   ├── BookFrame.tsx     # 书页线稿
│   │   ├── Cover.tsx         # 封面的构图、翻开动画与书签
│   │   ├── cover/            # 封面的各层：五角星法阵（流光）、书名与题签、预知之眼（交织眼睑、眨眼、瞳孔跟随）
│   │   ├── Leaf.tsx          # 翻页
│   │   ├── InkText.tsx       # 墨迹书写的文字
│   │   ├── Sigil.tsx         # 推演页的纹章（六芒星法阵）
│   │   ├── plan.ts           # 一次占卜的跨页顺序与书签位置
│   │   └── pages.tsx         # 提问页、回答页（单选 / 多选 / 刻度 / 叙述）、序章与描绘、推演页
│   ├── prophecy/
│   │   ├── WordCloud.tsx     # 画像的关键词云
│   │   └── ProphecySpreads.tsx # 画像的两个跨页（含更正），预言的两个跨页
│   └── components/           # 自 Atelier 移植：背景魔法阵、萤火虫
└── vite.config.ts            # 挂载 /api/oracle 中间件
```

## 内容修改

- 预言书的语气、提问规则、画像的写法：`server/prompts.ts`
- 画像的维度与条目（及是否必需）、问题数量的上下限、可推荐的方向：`shared/oracle.ts`
- 演示模式的内容：`server/mock.ts`
- 主题颜色与字体：`src/index.css`
